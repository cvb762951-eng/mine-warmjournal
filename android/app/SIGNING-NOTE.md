# Mine 更新签名

`mine-update.keystore` 是从 1.7.0 起用于安装包升级的固定签名，已被 `.gitignore` 排除。

- 后续版本必须继续使用这把密钥，并递增 `versionCode`。
- 不要删除或重新生成该文件，否则新安装包无法覆盖手机上的旧版本。
- 不要把密钥上传到公开仓库。
- 手机内数据应通过新版 APK 直接覆盖安装保留；先卸载旧版会清除应用私有数据。
- 换手机时仍需在旧手机导出加密备份，再到新手机恢复。
